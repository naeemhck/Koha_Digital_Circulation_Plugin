# Upgrade

Back up first, preserve the previously installed KPZ, record the current plugin/schema versions, inspect the replacement KPZ, and install through Koha's supported plugin upgrade workflow (Manage plugins → **Upload plugin**). Version **0.2.3** retains schema version **1**, introduces no new migration, and is safe to upgrade over the live shortcut-only **0.2.2** release. It combines the Koha 26.05 Circulation-home **Digital Circulation** button shortcut with the Phase 4B authoritative patron-return endpoint. It implements no renewal, revocation, or automatic-expiry behavior. The idempotent schema-1 installer uses `CREATE TABLE IF NOT EXISTS` and `INSERT IGNORE`; it never drops, recreates, or rewrites institutional data, and patch upgrades refresh only the recorded `plugin_version` stamp. After upgrade restart/reload services only as required, check Plack/Apache, health/version, plugin configuration, permissions, the Circulation shortcut and staff tool, existing plugins, and the unchanged portal. Regression-test every later 26.05 maintenance release; do not upgrade to 26.11+ on this compatibility claim. This document describes a release candidate; it does not claim **0.2.3** has been deployed.
