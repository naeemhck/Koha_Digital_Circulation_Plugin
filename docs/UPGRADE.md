# Upgrade

Back up first, preserve the previously installed KPZ, record the current plugin/schema versions, inspect the replacement KPZ, and install through Koha's supported plugin upgrade workflow (Manage plugins → **Upload plugin**). Version **0.2.3** retains schema version **1**, introduces no new migration, and is designed to upgrade over the live shortcut-only **0.2.2** release. It combines the Koha 26.05 Circulation-home **Digital Circulation** button shortcut with the Phase 4B authoritative patron-return endpoint. It implements no renewal, revocation, or automatic-expiry behavior.

The released schema-1 DDL remains unchanged and idempotent. After migrations, a dedicated transactional schema-state upsert updates the single schema-1 row's `plugin_version` from **0.2.2** to **0.2.3**, then strict verification requires exactly one canonical row with schema version 1 and the current plugin version before commit. A failed version write or invalid schema state rolls back the metadata update and fails the upgrade. This is release-metadata maintenance, not schema migration 2. Requests, loans, renewals, events, lifecycle values, and native Koha circulation are not changed.

The earlier undeployed 0.2.3 KPZ with SHA-256 `2130ce2c6385c2a506ee9899ad6e958c8266c896ffda1fb462215c896f0eb8ba` has a defective stale-version-stamp path, is superseded, and must not be installed. Use only the replacement KPZ produced from the correction commit and verify its recorded hash before any separately authorized installation.

After upgrade restart/reload services only as required, check Plack/Apache, health/version, plugin configuration, permissions, the Circulation shortcut and staff tool, existing plugins, and the unchanged portal. Regression-test every later 26.05 maintenance release; do not upgrade to 26.11+ on this compatibility claim. This document describes an undeployed release candidate and does not claim a live upgrade.
