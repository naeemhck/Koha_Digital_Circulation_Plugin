# Upgrade

Back up first, preserve the previously installed KPZ, record the current plugin/schema versions, inspect the replacement KPZ, and install through Koha's supported plugin upgrade workflow (Manage plugins → **Upload plugin**). Version **0.2.2** retains schema version **1**, introduces no new migration, and is safe to upgrade over **0.2.0** / **0.2.1**. It adds the Koha 26.05 Circulation-home **Digital Circulation** button shortcut only; it does not include an authoritative return endpoint and does not change request, loan, or event lifecycle behavior. The idempotent schema-1 installer never drops or rewrites institutional data; patch upgrades refresh only the recorded `plugin_version` stamp. After upgrade restart/reload services only as required, check Plack/Apache, health/version, plugin configuration, permissions, the Circulation shortcut and staff tool, existing plugins, and the unchanged portal. Regression-test every later 26.05 maintenance release; do not upgrade to 26.11+ on this compatibility claim.
