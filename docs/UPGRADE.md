# Upgrade

Back up first, preserve the previously installed KPZ, record the current plugin/schema versions, inspect the replacement KPZ, and install through Koha's supported plugin upgrade workflow. Version 0.2.0 retains schema version 1 and introduces no migration. The idempotent schema-1 installer never drops or rewrites institutional data. After upgrade restart/reload services only as required, check Plack/Apache, health/version, plugin configuration, permissions, the staff page, existing plugins, and the unchanged portal. Regression-test every later 26.05 maintenance release; do not upgrade to 26.11+ on this compatibility claim.
